# Nexus Mods 全站 UI 中文化覆盖设计

- 日期：2026-10-22
- 状态：设计已获批准，等待文档复核
- 项目版本基线：1.0.3

## 背景与问题

Nexus 当前覆盖率门禁只读取 `docs/evidence/nexus.txt` 的 230 行快照。该快照仅包含模组详情页和模组浏览页，因此 230/230 命中只能证明这两页的快照覆盖完整，不能代表全站。真实页面检查发现游戏目录、游戏主页、合集列表、图片/视频列表、新闻、论坛与模组详情仍有英文 UI；现有路由识别也缺少这些页面组。

当前基线 `npm test` 为 smoke 16/16、jsdom 12/12；`npm run coverage --silent` 中 Thunderstore 快照为 203/203 与 100/100，Nexus 旧快照为 230/230。直接匿名 HTTP 请求会触发 Cloudflare；使用 bsk 同一 Chrome profile 的任务标签可访问登录态页面，并通过同源只读 GET 获取原始 HTML，避免把已翻译 DOM 误当作原文。

## 目标

1. 按实际路由识别 Nexus 的首页、游戏目录/详情、模组浏览/详情、合集列表/详情、媒体、新闻、账户和论坛界面。
2. 对固定 UI 文案提供精确词条：导航、页脚、按钮、筛选器、排序、分页、表单标签、占位符、ARIA 标签、title、固定分类与枚举。
3. 动态计数、日期、相对时间等仅使用完整锚定模式；保留其中的数字、版本号和其他数据。
4. 保护动态内容：游戏名、模组名、合集名、作者/用户名称、模组与帖子描述、新闻标题/正文、评论/日志、文件名及用户输入均不翻译。
5. 将已审查页面的原始 UI 文本纳入回归证据，并用正向和负向测试防止新增词条误伤 UGC。

## 范围

### 站点页面

- `www.nexusmods.com`：`/`、`/games`、`/games/:game`、`/games/:game/mods`、`/games/:game/collections`、`/collections`、`/collections/:slug`、`/games/:game/images`、`/games/:game/videos`、`/news`、模组详情页（新旧 URL 形式）。
- `forums.nexusmods.com`：论坛首页、导航及论坛 UI 控件；主题、帖子、成员、板块介绍正文保持原文。
- `users.nexusmods.com` 及 Nexus 自有帮助/知识库子域：只翻可证实的固定 UI 标签、表单和控件；账户数据与帮助文章正文不作为 UI 词条。
- 指向 Discord、Patreon、外部新闻来源或其他第三方站点的页面不纳入本次翻译范围。

`www.nexusmods.com/community` 与 `/support` 在本次原始 HTML 检查中返回 404；不为这两个不存在的路由猜造页面词条。其真实导航目标按对应 Nexus 子域或第三方域名分别检查。

### 明确不做

- 不翻译名称、标题、描述、帖子/评论正文或文件内容。
- 不增加无锚定的子串替换、自动翻译或按词拆分的宽松规则。
- 不改变 cookie 同意、用户偏好、下载、上传、收藏、点赞、发帖或账户状态。
- 本阶段只实现并验证本地脚本，不发布 GreasyFork 或推送 GitHub。

## 方案与选择

### A. 只扩充全站 `global` 词库

改动最小，但无法区分游戏主页、合集、媒体、新闻和论坛中的同名词，也不足以验证页面路由漏项。

### B. 页面组词库 + 共享全站词库 + 原文快照回归（采用）

扩展 `nexus.detect()` 页面类型；共享固定导航/页脚文案仍放 `global`，页面独有标签放入对应组。所有动态正则完整锚定。基于原始页面 HTML 制作按页面组分段的 Nexus 证据快照，并在 smoke/jsdom 中验证路由、文本、白名单属性、数字保留、关闭后还原及 UGC 不变。

### C. DOM 上下文/子串式自动翻译

可以快速提高表面命中率，但容易把 UGC 中与 UI 相同的短词改写，违反既定边界；不采用。

## 实现结构

1. `src/locals/nexus.js`
   - 补全标题大小写变体及常用导航、页脚、筛选、表单、媒体和通知 UI。
   - 增加 `games`、`game`、`collection`、`media`、`news`、`forums` 等页面组，并按 host/path 明确选择；旧模组 URL 和新游戏路由都保留。
   - 覆盖用户实页上发现的遗漏项，包括合集分类/徽章/类型、媒体分类、排序方向、页码 title、新闻筛选、模组文件信息/权限致谢等。
   - 游戏名与模组名在带前缀控件标签中只翻静态前缀；名称部分原样保留，并使用完整锚定模式。
2. `test/smoke.test.mjs` 与 `test/browser.test.mjs`
   - 增加每个新页型的 URL 判定和关键固定 UI 断言。
   - 增加游戏名、模组名、作者名、帖子/新闻标题、描述、文件名和用户输入的负向对照。
   - 增加 `aria-label`、`title`、`placeholder`、动态计数与开关还原断言。
3. `docs/evidence/nexus.txt`（必要时拆为页面组快照）与 `CONTEXT.md`
   - 证据逐条来自 2026-10-22 bsk 页面或同源原始响应；不收录动态用户名、游戏/模组名称、帖子标题和描述。
   - 更新领域术语表中 Nexus 页型清单，使其匹配实现路由。
4. 发布版本号不在本地实现阶段预先递增；待用户决定发布时再按仓库发布流程处理。

## 验收标准

- 新增的原始 UI 证据行全部命中词条或已登记的纯数字/中文豁免；漏项清单为空。
- `npm run verify` 通过，保持 Thunderstore 覆盖与行为不变。
- jsdom 负向断言证明 UGC 与用户输入不变；属性、动态数字和“关闭后原文恢复”均通过。
- `git diff --check` 与构建语法检查通过；无下载/上传/账户更改等站点副作用。
- 最终报告明确列出覆盖页面、词条增量、测试结果和未能取证的页面边界，不以单个 100% 数值代替全站审计结论。
